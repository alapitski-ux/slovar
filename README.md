# Словарь из книг

Тренажёр английских слов: карточки EN → RU и RU → EN, оценки «знал / угадал / не знал»,
цвет запоминания от красного к зелёному. Работает в браузере телефона и ставится на экран «Домой».

Сайт публикуется из папки `docs/` через GitHub Pages.

## Как устроено

- `docs/words.json` — общий список слов (`id`, `en`, `ru`, `tr`, `ex`, `src`, `added`). `src` — название списка, например `EVU 37 · Глобальные проблемы`.
- Прогресс и слова, добавленные на телефоне, хранятся только на устройстве (localStorage). Копию можно сохранить в файл на вкладке «Слова».
- `src/components.jsx` + `src/app.jsx` → `docs/app.js` (`npm run build`).

## Добавить слова

Дописать объекты в `docs/words.json` (уникальный `id` = слово через дефис), затем закоммитить и отправить на GitHub.
Через минуту сайт обновится, прогресс сохранится.

## Локально

```
npm install
npm run build
node scripts/serve.mjs 8765
```
